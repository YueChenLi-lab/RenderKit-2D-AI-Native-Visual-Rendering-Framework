# Design System

主题定义在 `packages/design-system/src/index.ts`。`getTheme(id)` 返回独立副本。内容只声明语义、数据和必要布局约束，渲染器从主题读取视觉 token。

## 主题

| Token | Academic Minimal | Tech Dashboard |
| --- | --- | --- |
| 画布 | `#F7F5F0` | `#0B1424` |
| 表面 | `#FFFFFF` | `#142238` |
| 主文字 | `#152C36` | `#EDF4FF` |
| 次文字 | `#4B626B` | `#A5B8D0` |
| 主色 | `#006C67` | `#65E2C5` |
| 辅色 | `#B3612D` | `#F4BD6A` |
| 适用场景 | 科研、教学、公式推导 | Agent、系统架构、工程展示 |

共同基线：16:9，逻辑画布 1280 × 720，12 列网格 token，页边距 64，间距 28，圆角 12，边框 1。默认标题 48、正文 24、小字 18。所有尺寸以逻辑像素表示；PPTX 适配器负责转为英寸和磅。

字体默认 Arial / sans-serif。不同操作系统的替代字体会产生差异；发布前使用目标字体和目标 Office 版本复查。KaTeX 使用它自己的数学字体，静态 HTML 包含本地依赖中的数学样式及字体资产。

## 使用方式

只需修改 `deck.theme` 即可切换主题，不能在切换过程中改写文案、实验值或公式。图表使用主题 `colors.chart` 序列，文本、表格和图形使用对应的主色、表面色与边框色。

`layout`、`fontSize` 和 `color` 是有明确需要时的局部覆盖。审计器仍会检查覆盖后的越界、字号和对比度。不要把全部坐标与颜色写入示例内容，以免绕过排版规则。

## 视觉表达选择

| 内容目的 | 推荐表达 |
| --- | --- |
| 算法步骤、路线图 | ProcessFlow |
| 模块依赖、信息流 | ArchitectureDiagram，有向连接 |
| 精确实验比较 | ComparisonTable |
| 类别指标比较 | Bar Chart |
| 按序变化 | Line Chart |
| 关系展示 | Scatter Plot，注意横坐标编码约定 |
| 数学定义与推导 | FormulaBlock + 解释 |
| 图片、实验截图 | ImagePanel + 来源 / 说明 |
| 单一论点 | ContentSlide / TwoColumn |

## 审计约束

对比度依据 WCAG 相对亮度公式计算；审计器可能根据字号选择阈值。间距、留白、层级和均衡属于启发式质量信号，不是审美真值。背景容器与其内容的有意覆盖应标记或按层级识别，不作为非预期重叠。

下一版可扩展字体嵌入策略、机构主题和内容自适应布局，但必须在共享 IR 和双渲染器之间保持数据一致性。
